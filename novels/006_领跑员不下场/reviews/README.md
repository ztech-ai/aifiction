# 工作稿审读记录

下列为 r1 的编辑复核，读者试读数据尚待采集。

河汀前三十公里的合约目标为一小时五十四分三十秒，上下可差半分钟。魏真的芯片在三十公里记下一小时五十四分三十二秒，报酬一千八百元。正式报名、雇用费用与后程比赛成绩各有来处。审核采访与重逢时还要看杜苇何时有机会亲口说她当时为什么没追。

岬湾半程一小时十九分五十五秒，后半程一小时十八分五十二秒，总成绩二小时三十八分四十七秒。魏真第三，最后超越的姚砚本人看见了魏真的鞋底。河汀那笔领跑钱、岬湾排名和训练陪跑的新活各有付款人。收尾在小木门前交班，剩下的八公里由新人自己跑。
