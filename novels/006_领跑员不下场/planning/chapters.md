# 二十五章计划

| 稳定 ID | 章名 | 行动与后果 |
| --- | --- | --- |
| ch0001 | 三十公里处 | 河汀马拉松，魏真以正式号码领跑到三十，夺冠热门杜苇请她再带一段。 |
| ch0002 | 车门开着 | 过约定点后她未上收容接应车，带过顶风桥，接受杜苇要自己跑的意思。 |
| ch0003 | 自己撞的线 | 她用自己的脚赢了区域赛冠军。杜苇第二，镜头让两人的拥抱落空。 |
| ch0004 | 撤回一条消息 | 原本口头敲定的下站陪跑和其他询价相继撤走。她发现自己曾在公开采访替杜苇解释输因。 |
| ch0005 | 一张靠窗的票 | 奖金实收后魏真用自己的名字买第一张自己付钱的机票，去十五周后的岬湾冬马。 |
| ch0006 | 不按表吃的饭 | 她在姐的面馆恢复，见到下班去跑步的送餐员沈铃，两人试着结伴。 |
| ch0007 | 快了十一秒 | 恢复后第一次质量课，为卡表越跑越快，跑漏与沈铃约好的交接。 |
| ch0008 | 六圈半 | 她加练失败，中止十二圈，第一次把没完成的六圈半写进日记。 |
| ch0009 | 没有影子的人 | 沈铃请她从后边看跑姿，魏真抢着带速，对方索回自己的跑道。 |
| ch0010 | 小路朝上 | 独跑上坡误判风和节奏，魏真学会用整段体感而非瞬时数字调整。 |
| ch0011 | 把手表还我 | 沈铃自行挑路线，魏真撤掉强加的表，二人重新谈清观察任务。 |
| ch0012 | 最后一个号码 | 魏真拿到本地十公里赛最后一个名额，拒绝免费帮人做宣传兔。 |
| ch0013 | 三个人的十公里 | 十公里实战中追错集团，被后程赶上，没跑出理想成绩。 |
| ch0014 | 等她先开口 | 赛后重看影像，杜苇在电话里解释对旧采访的不满。魏真发出补充，让杜苇自己讲述。 |
| ch0015 | 凌晨四点的面 | 赛前训练周期收束，魏真把减量周当作训练的一部分，想交回面馆钥匙，姐姐为她留好回家的门。 |
| ch0016 | 玻璃外头的云 | 乘机到岬湾，看见自己真金白银的成本，同机的对手也会害怕。 |
| ch0017 | 房间里的第四条腿 | 便宜旅馆床腿摇晃，和同屋女跑者姚砚把各自争取的东西说开。 |
| ch0018 | 风从右边来 | 走赛道识别桥面横风，自己定下头程限速和丢瓶备选。 |
| ch0019 | 起跑的钱 | 赛前有人出钱让她保送前半程，她自行衡量后坚持以选手身份起跑。 |
| ch0020 | 桥上的空位 | 前半程舍弃强者的迎风位置，和近速的几人轮带过桥，姚砚自行加速。 |
| ch0021 | 二十五公里的纸杯 | 二十五公里错过个人饮料，利用公共补给调整，顶住一个冒进提速。 |
| ch0022 | 你再带我一段 | 重遇杜苇，魏真说清轮带约定而非替对方做主，二人借彼此过风道。 |
| ch0023 | 还有三公里半 | 最后三公里半，杜苇先冲，她追近姚砚，留住弯道出线的位置。 |
| ch0024 | 第三个人的名字 | 她获第三、刷新个人最好成绩。第二属于杜苇，她按自己的名字领成绩。 |
| ch0025 | 下次坐哪边 | 奖金、工钱与关系各自落定，她承接边界清楚的训练陪跑工作，留出自己下一场。 |
