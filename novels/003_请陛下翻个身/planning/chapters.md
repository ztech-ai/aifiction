# 分章路线

| ID | 标题 | 这章实质行动与后果 |
| --- | --- | --- |
| ch0001 | 准 | 桑口停舟，卢六斤见帝死，替申冤的蒋九娘准许领尸与领工钱分开。 |
| ch0002 | 请陛下翻个身 | 余公公与六斤给遗体翻身，验出冰凉，请医官、记注官分别记时。 |
| ch0003 | 耳朵也得画押 | 记注官陶青录下听见的口宣，六斤签明自己是帘内出声者，例限施行范围。 |
| ch0004 | 席底那只脚 | 六斤上岸助认三具遗体，九娘辨出弟弟，另一户留下没有销钱的领尸回执。 |
| ch0005 | 三里谢恩 | 秤盘埠三里跪谢，百姓铺开工票，六斤才知父亲那份也是个冤账。 |
| ch0006 | 借 | 冷雨压滩待核，六斤再次冒声借出御膳米，留下须偿还的实债。 |
| ch0007 | 一锅两样米 | 膳工拒绝把自己的份一并施舍，分锅按勺记借，余公公遣人告太子。 |
| ch0008 | 殿下来收账 | 第三站合水渡，太子梁延上船请撤分单，恐河仓质票全被当成废纸。 |
| ch0009 | 跪稳了 | 六斤先请太子跪稳再掀帘，太子亲闻死期，拒绝让太医挪时辰。 |
| ch0010 | 旧令上的虫眼 | 太子、陶青验早已颁行的监国常令，等京闸勘合，不须伪造遗命。 |
| ch0011 | 一炷香的买卖 | 户曹祁适愿保六斤换其改口，六斤拒绝改口，米铺和夫户原都攥着真债。 |
| ch0012 | 把鼓槌给我 | 六斤敲鼓发丧，自认假口谕，已发的尸签和粥当场面临追回。 |
| ch0013 | 请原告坐 | 九娘与米铺孟婆子同席请命。太子暂以本名承接已行两件事，开船审欠。 |
| ch0014 | 一张票的两端 | 米铺取回质票，六斤将票与工夫边簿拼合，确认部分工钱已换粮。 |
| ch0015 | 进仓先脱鞋 | 六斤随祁适实盘船仓，查见借支粮救了另一处断炊渡工，没有整库现钱。 |
| ch0016 | 三十六盏灯 | 夜间分户举灯听账，口述与票据互核，挑出冒记的整户“讫”。 |
| ch0017 | 我爹按的圈 | 六斤交出父亲那张空白票，自认曾代画圈，他家也须扣已借的米。 |
| ch0018 | 堂下不许哭 | 一名抄手吐露奉命成批销账，祁适认下挪支却拒绝让米铺蒙冤。 |
| ch0019 | 谁买这顿早饭 | 太子用东宫账补御膳，和户曹论定可立即支用的修堤尾银及分期钱源。 |
| ch0020 | 榜上留白 | 三联清册分工户实得、质米、首付和余欠，保护户名，九娘坚持给无名和异议留有去处。 |
| ch0021 | 京闸闭着 | 京闸催船进宫交遗诏，太子拒带未签账靠岸，六斤送常令和岸账去勘合。 |
| ch0022 | 换印 | 两处旧令勘合，京闸当船奉监国印，太子正式签付三成首款、后续钱源和申覆令。 |
| ch0023 | 活人先下船 | 各方先按清册领到首笔，失名工夫认出是柳生，工钱仍留女儿。御船靠岸。 |
| ch0024 | 两个字的刑钱 | 六斤与各方分别受审，矫声判徒三年并永革吏籍，祁适受徒、倪寿退职服役，余公公夺俸，医官无罪。 |
| ch0025 | 轮到谁说准 | 三年后六斤出役，查到余欠已清，民间请他读契，苇索女工把损耗责任缩小到自己做的绳，再亲口答准。 |
