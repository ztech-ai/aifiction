# 全书工作稿审读记录

## 第一卷《来船敲三下》

本次复核对象为《来船敲三下》二十章工作稿 r1。跨章编辑读过谜底，重点核对前文的承诺怎样在后文兑现。这里记录编写与复核时发现的问题。目标读者的阅读感受仍待实际试读。

| 范围 | 初稿的阅读问题 | r1 的处理 |
| --- | --- | --- |
| ch0001—ch0005 | 想相信修理工凭手艺接单，读者得先看见燕子号修妥的凭据。随后清单上那个“零”还应容得下另一种解释。 | 港内补压与燕子换件后的复检落在正文。白露号那一栏的表头起初超出屏宽，待冯荞露面才看清它数的是乘客。 |
| ch0006—ch0013 | 救人的拖轮同时还是货船。船回了几趟、货筐和船上那盒葱到了哪里，影响读者能否相信这趟临时救援。 | 每趟三席，两次载人、中间空返。三棵葱在港里交还主人，前来拖船壳的鲁麦收回空筐。蓝布簿由阿岑还给冯荞，随后是冯荞自己携簿返坞。 |
| ch0007—ch0017 | 老杜为能马上结钱的活离开。他若回船就自动算作伙计，或者坞主一句话就能把人留下，先前的争执会失去分量。 | 交壳后按老杜实际守过的时间付钱。他后来报了单班的价。试靠叫停后，阿岑动用自己做修理工的收入，请各船按各自能留的时长候班。 |
| ch0015—ch0019 | 客人买的是抵达检修台的服务。一名老人只要点个已到，就有人可以提前收钱。 | 先空试、载重、保压，再由冯荞走第一趟。候接线挨着检修台侧廊门口。老人亲自走到徒弟跟前，最后一格才亮。 |
| ch0001、ch0014、ch0019—ch0020 | 接连三次“收到钱”容易削弱书名和末章的呼应。 | 第一笔来自拆运白露号，第二笔来自苇子号接渡。第二十三个港日，如意号付了诊听与修理费，阿岑也在自家坞的首个薪期领了一份工资。 |

**保留的代价**　季武等到了第一笔退份款，却错过那间带锁的小屋。六位渡工约定三十港日到期后再谈，掌握这座桥的人也有权在下一次谈判里改变主意。[第十一章](../chapters/ch0011_不卖桥的人.md) · [第十九章](../chapters/ch0019_数到最后一个.md) · [第二十章](../chapters/ch0020_来船敲三下.md)

## 第二十章时，读者已经读到了哪里

按三十章完结，第二十章是全书三分之二处。救出六名渡工、拒绝独家、结清拆船款、把十二位换班工交到检修台、自己领到工资，已经使“拿个破坞有什么用”有了答案。第十九章与第二十章连续给出成功，如果此后仍是来船、诊修、收钱，后十章会像营业流水账。更值得等的是三个已有代价的选择。

| 已有进展 | 第二十章留下的疑问 | 终篇的回答 |
| --- | --- | --- |
| 检修台在翻修，临时泊点有工人肯付钱走。 | 原客口一开，谁还会来找阿岑？ | 客口复开，她拖着坞去找船。七艘冷运短驳都亮红，她给一块没有门的实心板也测出了红灯。六家留下好门，肯付查明白的工钱，其中两家订下巡修。 |
| 这份工资让阿岑敢当坞主。 | 一笔大的换件收入摆在面前，她会怎样对待客户？ | 六份换件报价撤回。唯一真有病的栗子号停航，查明故障的坞收诊断费，需要专用修位的活由别家做。满婶主动把货分出去，失掉这一趟运费。 |
| 两位渡工开始收退份款，季武已经错过一间小屋。 | 三十港日一到，两个要退出的人能否真的走？桥留下以后，坞怎么办？ | 四人用个人积蓄按原价补清两人的余额。退份的人仍能接有工资的班。夜班桥和巡修坞各自有主顾，季武用自己的钱选了能锁门的房间。 |

## 第二十一至三十章复核

依据三十章 r1 工作稿进行编辑通读，提前知道谜底。本次没有读者试读样本。以下几处在组装全书阅读稿前已回到源章核对。

- 栗子号在二十四章验两次时舱里仍有货。二十五章卸掉货筐以后，空舱时偶过偶漏。重新装重筐，门框每次在同一个角偏离，新封条也填不上。[第二十四章](../chapters/ch0024_好门修不修.md) · [第二十五章](../chapters/ch0025_剩下那扇门.md)
- 发运保持原舱限和温区，白鼻头提前一天离港，另五条在正式窗口启航。栗子号空舱入修单独报到。桥上送人、货吊运筐，诊断、运费、桥租各自付给干活的人。[第二十六章](../chapters/ch0026_一船先走.md) · [第二十七章](../chapters/ch0027_空船也有到港时刻.md)
- 棚里先许试合，灰桥试完回坞。六人到期议妥、四位桥主签租以后，才正式迁到棚外小趸。三个月夜班租约首月预付，这笔钱留下履约。[第二十八章](../chapters/ch0028_该谁掏这笔钱.md) · [第二十九章](../chapters/ch0029_还差一个指甲盖.md)
- 前后照应落在阿岑当初考驾驶时多等的一下。终章由田梨等工人取出饭盒，再放货船进坞。阿岑隔着客船窗看见，安心休了半班。栗子号已经修妥并重新满载挣钱。[第一章](../chapters/ch0001_工资请自提.md) · [第三十章](../chapters/ch0030_我买一张票.md)
