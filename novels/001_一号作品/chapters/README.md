## 登记方法

- 文件名由稳定 ID、下划线与短标题组成。命名示例为 `ch0001_短标题.md`。正文建成后填入相对本页的真实链接。改标题优先改显示标题；移动文件时同步所有引用。
- 分配新 ID 前核对本表、计划中已占用的 ID 及并行任务。插章用新 ID，调整展示顺序；重排保留原 ID。查询前章以展示顺序为准。
- 实际摘要用几句交代谁做了什么、结果怎样、章末还有什么制约后文。对秘密或误会写清“谁相信什么”。从指定稿次核对，只收该稿已经写出的内容。
- 稿件状态可用“草稿／当前稿／备选／已弃用／用户定稿”。主创完成必要复核后可将稿件纳为当前稿；“用户定稿”须有用户认可。保留的备选注明依据版本，清洁阅读稿只收指定版本。
- 修订标识用每章递增稿次；未提交时可写 `r1（工作稿）`。大幅换稿前确认旧内容可从指定 Git 版本或有标识的快照恢复。指向历史提交前先确认其中确实保存了该章该稿。
