# 人物与关系

人物的底色与可调动的资源列在这里。下表含两卷的角色变化；判断人物在某一章能知道什么，回查[章节](../chapters/README.md)与[连续性](../memory/continuity.md)。

| 人物 | 要什么，有什么本事 | 关系、压力下的选择与声音 |
| --- | --- | --- |
| **岑青／阿岑**，女，七码头修理坞的新坞主 | 想让手艺养活自己。知道旧船最先需要查什么，能向船主开价；没有发动机，也没有替别人垫账的本钱。 | 最初把“我能干”错当成“我们都能等钱”。找到活人会停拆，试靠有危险还须再停一次，并承担待班费。到了外环，她肯撤六张换件报价，只收查明毛病的钱。她看人的第一个念头常带着修理工的判断；心里算出亏多少，比嘴上承认得快。 |
| **鲁麦**，女，燕子号船主 | 愿意拿一程拖航换检修，想把自己的船当家做主。多次从驾驶位观察别人看不见的位置。 | 能与阿岑同出一趟，也能反对把长期使用权交给青穗。她最可靠的时候是把人送到该去的地方。讲话喜欢把事落到“我这一趟”上。 |
| **老杜**，男，长脚号船主 | 船要耗油，等一份未到账的工钱就可能错过另一班。他愿意回头接明码实价的一单。 | 退出照守完该守的班，带来付费消息也并没有重新把船押给阿岑。答应多少说多少，常问哪一班、什么时候结。 |
| **田梨**，女，七号勺船主 | 肯在白露号旁留守，能和阿岑一起从重量、留置物和当班人手把拆运账算清。 | 鲁麦去送人、老杜退出时，她的在场使阿岑仍有搭手。她指出让人干等、把桥扔上秤各会造成什么后果；少用打气式的对白。 |
| **冯荞**，女，炊事员、渡口工 | 同另外五人在白露号尾段值守，知道谁在用桥、如何认工记账。想让愿留和愿退的人都能自己开口。 | 敲舱壁求应答，交出蓝布潮班簿，仍保留自己说话的权利。能说明老规矩，也容得下同伴说“我要钱”。她的分量来自经手的工班和接过的人。 |
| **邵宽**，砾港窗口承办人 | 手里有拆运交接和分列受理的权限，须交代何物交了、谁有凭据。 | 一张客票统计不足以确认船上没人，一份称重回执也处理不了桥的产权。他能给分列申请找途径；他签的手续有明确范围。 |
| **沈照**，女，青穗航务经理 | 要给通勤船买到可靠泊位，付得起保底，独家能减少自己船班的不确定。 | 她的条件对缺钱的人很有吸引力。买不到独家，她还能下单买一趟服务；叫停时要知道这班人怎么安置、谁负什么责。报价和追问都具体。 |
| **满婶**，栗子号冷运短驳船主 | 了解外环货场谁的船能装哪一筐，跑空一趟就没这趟运费。七家托她来找阿岑，她能牵头问价，各船仍各自付费。 | 其他六扇门查清了，最亏的是她自己。她愿交出真有毛病的船，让别人挣自己这一趟的运费，还替大家排货吊和船次。她知道该让谁先走，也肯自己付大修账。六周后，她带回了自己重新揽来的满舱冻梨。 |
| **季武**，渡工、灰桥原共有人之一 | 想用退份钱租一间能从里头锁门的小屋。看重每回按原份同时兑付、没收到的余份仍归自己。 | 第一次听到好价就敢说“我想卖”。他会逐张摊开回执问清最后一点余额，也会把门关上，自己听听屋里安不安静。谁都替他想不到哪间更合适。 |

**关系的边界**　首单同行的是三位新船主和阿岑；其余三十三条抵薪船各有主人。白露号尾段的六位渡口工是一个有分歧的小群体，冯荞也不能替另五人决定份额。读到“工友”时要辨清是哪一批、谁当时在现场。
