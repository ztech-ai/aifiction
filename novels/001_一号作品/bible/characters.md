# 人物与关系

准备人物的首次重要行动、判断一句对白或检查动机时使用。只为本阶段有作用的人物补条目。以下为可重复使用的卡片，填写时以姓名或稳定称谓作小标题。

## 人物卡

| 基础设定 | 填写提示 | 已采用内容 |
| --- | --- | --- |
| 姓名、身份与可辨认的特征 | 选会改变别人如何对待此人的一两项特征，记必要称谓。 | |
| 欲望、动机与需要 | 此人眼下向谁争取什么？自以为想要的东西与真正怕失去的东西有何距离？ | |
| 价值与矛盾 | 两样都想保住的东西是什么？哪种做法会使此人觉得自己越了界？ | |
| 能力、资源与限制 | 写能力来源、动用它的代价，以及即便善于此事也会碰壁的处境。 | |
| 压力下的选择 | 给出一种会迫使其表态的压力，写此人可能牺牲什么。此处是推演。 | |
| 语言习惯 | 面对不同对象，如何称呼、回避、争取或打断？记有区别作用的用词和沉默。 | |

### 关键关系

| 对方 | 彼此想从对方那里得到什么 | 亲疏、权力或误解从何而来 | 何种选择会暴露这层关系 |
| --- | --- | --- | --- |

### 计划中的变化

尚无。需要时写转折条件及可能方向，例如坚守、逐渐显露、倒退或改变。正文已写出的关系变化和人物所知，附章 ID 与稿次记入[连续性记录](../memory/continuity.md)。

## 自检

若把这次选择交给另一个人，代价或结果会怎样不同？此人说了假话、信以为真或故意沉默时，读者从已给的信息能分辨到哪一步？
