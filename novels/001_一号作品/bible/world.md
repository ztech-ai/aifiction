# 灰环与砾港

本卷在虚构的灰环小行星带、砾港及周边航程内展开。居住、办手续、清分、吃饭可以在港内进行；拆运在退役客轮白露号旁，试靠用港外指定临时泊点。人员可乘接驳小艇往返，留置中的坞不会随一个人回港。资产位置和各章在场者见[实际记录](../memory/continuity.md)。

## 什么属于谁

| 资产或凭据 | 权利、限制与成本 |
| --- | --- |
| 三十六条旧船、七码头修理坞 | 北斗砂业对三十七人抵薪，签号决定挑选顺序。三十七人各自持有其所得。坞由岑青持有，无独立航行动力，有维修能力。三位船主的拖航靠协商取得，合作结束后仍各有船。 |
| 白露号主体 | 属另外承接的退役客船拆运单。拆运以交接称重结算，出航者先垫推进剂，发现活人须停拆。接到订单、分列申请获准、取得预约、实款到账是四个不同节点。 |
| 灰桥 | 白露号尾段可分离的旧伸缩登乘桥，是渡口工出份买的。桥未列入抵薪财产，拆卸不会把它过户给坞主。试营须记录同意、异议与未兑份额。愿退者从桥的实收租金逐步获兑；运营者另按工班计酬。 |
| 蓝布潮班簿 | 认工签记和老桥使用记录，可与经手人互证，供分列与试营协商之用。它不能让持簿者代其他人投票。客票统计中乘客数为零，记录的范围没有覆盖值守渡工。 |
| 青穗的订单 | 独家与月度保底是一笔可以拒绝的长期交易。普通客户按单预约、按约结款。沈照能向自己的通勤船苇子号派单；坞与桥上的劳动和产权另算。 |

## 能听见什么，能靠上什么

作业区低重力，拖动并停稳修理坞需要船、有窗口和当班的人。真空隔开时，空气声到不了另一艘船。船体或传力杆接触后，敲击可沿固体传来；人在有空气的舱内可以听到声响。工人用三下敲击告知“有人”，辨清来源、对答内容仍需接触和现场判断。铜铃、蓝漆价牌保留为坞上的旧物。

两处旧安装孔存在永久错位；到试靠时，要让人物有亲见的迹象再下判断。船坞、桥、客船各自就位不等于已经有人通过。旧轮痕、老渡工的用法和蓝簿是判断灰桥曾可浮动搭接的不同证据，试验次序从空载到熟手，再到乘客。避免把港区习惯写成现实航天规范。[事实核查边界](../research/README.md)

**结算尺度**　当地计价用“点”。首单拆运款先对实际垫油与工班，老杜已守的班记给老杜；桥上营业收入另账。报价和候船的每个窗口都占用时间，叫停后应当说明等候的工人靠什么拿这一班钱。详细金额如正文采用，应连同来源章进入连续性记录。
