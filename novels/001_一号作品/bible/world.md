# 世界、地点与行动条件

规划或修订依赖某项规则的情节时填写。从人物眼下要办的事倒推，找出读者理解其成败所需的条件。短篇可能只需记一处地点或一条社会规矩。

## 已采用的背景与规则

| 项目 | 要落实到行动的条件 | 本作设定 |
| --- | --- | --- |
| 时间、空间与社会关系 | 时间跨度、季节、距离、出入资格、身份或习俗实际改变了谁的行动？ | |
| 权力与资源 | 谁能分配、隐瞒、许可或拒绝？资源短缺时谁先承担后果？ | |
| 能力、技术或制度 | 生效条件、限制、代价、失败方式是什么？若有例外，它有哪些先例与可见后果？ | |
| 地点与道具 | 关键地点能接触谁、看见什么？重要物件从何处来，怎样到手，有何用途与限制？ | |
| 信息取得方式 | 谁能接触消息，经谁传来，需要多久，传递中会在哪一步变形？ | |

## 现实依据与虚构取舍

| 影响情节的现实问题 | 对应研究条目与核验状态 | 本作采用的条件或有意虚构的差异 | 若依据变化，需复核何处 |
| --- | --- | --- | --- |

现实事实的原始来源、日期和核验过程放在[研究入口](../research/README.md)。未知之处标“待核验”。创作主动设定的规则在上栏写清适用范围。某件道具后来到了谁手里、谁在何时得到消息等变化，按来源章和稿次记入[连续性记录](../memory/continuity.md)。

## 自检

同一条件用于对立双方时，结果是否讲得通？关键人物行动前，有时间、有渠道取得其依赖的信息吗？若解决难题必须启用例外，读者此前在哪里见过成立的条件？
