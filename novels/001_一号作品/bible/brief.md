# 创作简报

作品 001，《发工资那天，我领了一座船坞》。用户从第六轮科幻备选中选中这一题，委托写前二十章。题案定位为太空打捞、小人物逆袭的长篇。第一卷《来船敲三下》有独立的工作、危险、收款与收尾。后卷篇幅和连载安排待定。[原始题案 01](../memory/科幻20案.md)

**保住的画面**　矿业公司发不起工资。三十七个人挑抵薪旧资产，修理工偏挑没人愿要、连自己都开不动的坞。等新船主回来排检，她用头一次免费换一程拖航。第一单要拆的客轮报着零人，舱壁里却有手在敲。展开版本采用女性修理工岑青，抢到挑选机会与得到合伙人的信任，是两件要分别挣来的事。

**给读者的回报**　面向想看职业本事、买卖交锋与团队冒险的通俗科幻读者。较早的选题反馈要求开局快、冲突具体。先让人好奇她挑的破烂有什么用，再让人担心免费检修值不值那一程。解决敲击来历之后，继续追问六个人怎样拿回随船走了多年的东西。胜负要可见，譬如欠账上的数少了、伙伴带自己的船又来了一次、等船的人真能从这里回班。

**经营与情感**　不把工友写成三十六件随坞附送的资产。生意会散，友情可以留，散伙的人也该拿走已经挣到的钱。对手的条件要好到让阿岑真想签。她能按下停工，也得付得起工友留下来多等的一班。结尾给读者一份新工资和一艘有人应门的坞。

本书地点、企业、航务规则均属虚构。技术细节从人物当下要完成的动作进入，经营数字只在改变选择时使用。首卷采用的细化选择见[工作总纲](story.md)与[分章计划](../planning/chapters.md)。冷库创业企划已归档于 Git 提交 `b0deeac`，不向本作移植其人物、订单或企业史。
