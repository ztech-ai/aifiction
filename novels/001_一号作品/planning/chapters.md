# 第一卷　来船敲三下

本卷在灰环小行星带的砾港周边完成；二十章收束一单生意、一个新泊位和一支自愿合作的船队。以下是动笔依据。实际发生与采用版本见[章节索引](../chapters/README.md)。

| ID | 章名 | 情节支点与交接 |
| --- | --- | --- |
| ch0001 | 工资请自提 | 岑青，人称阿岑，女修理工。北斗砂业清算，以三十六条旧船和七码头修理坞抵三十七人的欠薪。抽的是挑选顺序，她第一签拿无动力旧坞；保留前端铜铃、蓝漆价牌。 |
| ch0002 | 谁肯拖我一程 | 六小时后旧船等检。阿岑首检免费换拖航，鲁麦（女，燕子号船主）第一个合作。传力杆传来三下回音是工友约定“有人”；真空不传空气声。其他人可各自离开。 |
| ch0003 | 拆一艘空船 | 窗口承办人邵宽交代退役客船白露号的拆运活：按交接称重结款，推进剂先由出航者垫，遇人需停拆；出发船只有燕子号、长脚号（老杜，男）、七号勺（田梨，女）三艘拖坞。其余三十三条各有去处。阿岑为争首单把底价压得太低。 |
| ch0004 | 三声 | 四船贴合白露号，在动力停转的旧船听到来自内部的三下敲击并能问答；阿岑按停拆单，全队暂停计件。 |
| ch0005 | 六副碗筷 | 阿岑随鲁麦进去，找到炊事员冯荞（女）等六名活人，都是住在尾段值守的渡口工；人可行动，有有限给养。管理处交接单上的零是客票系统的乘客数。敲的是冯荞。 |
| ch0006 | 先送人 | 鲁麦用燕子号分批或一次将六人安全送回砾港；阿岑、老杜、田梨随坞留在白露。冯荞交给阿岑一本蓝布潮班簿，记录老工人随身渡桥和每回认工签记。六人脱险已兑现；不拿人抵货。 |
| ch0007 | 长脚号退伙 | 老杜要看得到钱，退出首单回港接活。临走仍把该守的一班守完。阿岑承认不该替人许诺垫油，坞边只剩田梨、七号勺与白露。 |
| ch0008 | 卖不了的好铁 | 田梨与阿岑算出拆主船壳可结账，但尾段灰桥（旧伸缩登乘桥，工友合购，可独立拆卸，未列抵薪财产）若混称即归废料。有人出价收灰桥；阿岑回绝，接到返港重新报价的邀请。 |
| ch0009 | 第一张空桌 | 砾港小食堂，冯荞、阿岑、已返港的鲁麦等翻蓝簿查桥归属。用接驳小艇往返，坞仍在白露旁。六人不全愿留下灰桥；把署名和异议如实记下。 |
| ch0010 | 包年的价 | 青穗航务经理沈照（女）给阿岑可兑现的月度保底和独家进坞权。阿岑想签，鲁麦为自己也要当独立船主反对。沈照真能垫钱。 |
| ch0011 | 不卖桥的人 | 冯荞拒绝阿岑代言，提出过渡方案：同意用桥者限期试营，先用实收租金兑付愿退份者，保留未兑者份额；须真实靠船挣钱。老杜带第一条付费消息，不等于重新入伙。 |
| ch0012 | 半口饭 | 邵宽准主体船壳、独立灰桥分列，暂认蓝簿与证人；主壳按交货结算，灰桥单独试靠，取得预约而非现金。阿岑弃独家，沈照答应只按单交易。港区有一个即将错过的废料驳船交接窗口。 |
| ch0013 | 把船拆成两张单 | 回白露，鲁麦再来，田梨守住船坞，阿岑等分离灰桥与主壳，主体交给废料驳的机会逼近，银行未付款。 |
| ch0014 | 第一笔真钱 | 主壳过秤交驳，拆运实款到账，按实际垫油与工班清分；老杜当初守的那班照给。阿岑分到的钱少得可笑；钥匙未给青穗。灰桥保住，尚未营业。 |
| ch0015 | 有人来靠 | 沈照以普通客户预订第一单试靠：青穗的通勤船苇子号，接的是一班换班工。鲁麦领拖，老杜只承诺一个付费拖班，公开时价，桥要拖到砾港外指定临时泊点。 |
| ch0016 | 两个孔 | 试靠中止于发现坞上两处旧安装孔位有永久错位，硬靠会伤桥。阿岑本人当面叫停，苇子号在附近等下一窗口。交接给17章时无人通过、没有伤员，船坞与灰桥已在临时泊点，费用开始增加。 |
| ch0017 | 空班也算一班 | 人在临时泊点，阿岑付停工待命的钱；鲁麦想到自己驾驶位看到的车轮痕，老桥曾经是浮动搭接，冯荞依蓝簿、旧习佐证。问题有解但要试。 |
| ch0018 | 谁走第一步 | 上空载试，低风险验证后由冯荞作为老渡工走第一趟；不能让乘客替试。阿岑与沈照重新定实收服务边界，沈没有买断。 |
| ch0019 | 数到最后一个 | 苇子号换班客顺利通过，桥的经营收入开始兑给愿退份的人，桥由共有人持有，坞属阿岑；实际值班者按班拿钱。收掉白露与六人及敲击回响。 |
| ch0020 | 来船敲三下 | 数周后营业日：新船靠、已退出工友有活也可来。三十七人各保产权；阿岑从不能挪动的一只坞变成有伙伴的独立坞主。收读者期待的第一份新工资，修补最初拖欠的人情，结在一次有人应答的敲门声，不吊未完的生死危机。 |

视角为第三人称贴近阿岑，灰环交易结算用“点”；各票金额少写，绝不把三十七人的产权合并。近距离靠船低重力、空气声条件和人力班次都构成限制。交接可增次要细节，不改人数、主线、产权与结束状态。每章给人物一场需要亲手完成的事。
