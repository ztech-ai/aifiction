# 研究与核查

灰环、砾港、北斗砂业、资产抵薪条款、拆运合同、工班制度、灰桥认份和通行安排均为小说设定。写作时按[世界规则](../bible/world.md)维护。清单上的“零”取决于统计对象，具体指哪张单、谁签的、数的是谁，须回查正文。

涉及物理常识时核对声音传播是否有介质、拖带和停靠是否需要动力与协作、低重力场景中物体是否仍有惯性。当前没有外部资料支持将书中的机械构造、操作顺序、合同规则或计价推称为现实行业标准。后续需写实核查时，记录具体主张、作者或机构、条目与出处、核查日期、可佐证范围和受影响章节，将虚构改造另列。

早期选题用过的受众材料只服务当时的选题讨论，不提供本作技术事实。此前冷库创业方案及其商业史来源可在 Git 提交 `b0deeac` 的本路径查阅。
