# 工作稿审读记录

下列为 r1 的编辑复核，读者试读数据尚待采集。

三千册是印出来的实物。第一场读书会的四把椅子里，只有费巧掏出一笔二十元意向金。它是购书款、订金还是买断改写权，会怎样影响她以后说“不”的余地？复核时同时回看浴室准许转述的范围、账上进出的二十元与新版最后一页，避免把一个读者写成作者买到的素材。

旧版零售一千册、团购一千八百册、样赠和水损各一百册。收入 56,400 元，购货 24,000 元，仓运等实付 10,400 元，投入的 30,000 元最后成为 52,000 元。新版另付两次 9,000 元。第一位新读者买完，窗口还等着余鲤卖的有 1,499 册。费巧可以把话收回，也能自己指出末页的母亲为什么多了一只手。
