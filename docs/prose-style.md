# 自然表达与文风审校

读一段文字时，先说清楚想让读者经历什么。一声叫错的称呼，可能比一段关系说明更准确；隔了二十年的事，有时也只须叙述者用一句话交代。用能指给人看的句子、阅读效果和信息来判断修改。词频、标点数量和“AI 率”不能衡量一页小说写得好不好。

## 接手一段文字

先看任务范围、文本类型、目标段与相邻语境。查作品的 `bible/style.md` 与涉及人物的声音：谁在叙述，离人物多近，时代和关系允许他说什么，心理以什么形式进入句子？如有用户认可的本作品片段，记清来源和适用范围，只参考相应写法。没有样稿就用简报支持的暂定风格写，待读者或作者反馈后再调。[文风模板](../templates/novel/bible/style.md) · [按任务取用资料](context.md)

正文要让人听得出谁在说话、经历了什么。梗概可以直说行动、条件与后果。项目说明需要让人找得到文件、办得成事，标题、表格和必要术语可照常使用。修说明文时把路径、命令、稳定 ID、数值和链接目标逐项对照。

## 在原文中找证据

| 阅读时遇到的现象 | 回到句段做的检查 |
| --- | --- |
| 抽象形容词连用，情绪却没有分量 | 已写的动作或想法中，哪一点足以传达意思？材料只支持概述时，留一句准确概述。描写所用的比喻应在此人经验之内。 |
| 对白、心理、旁白讲了三遍同一件事 | 划去一处试读。若损失了人物自欺、叙述者的反讽或情绪加深，保留产生差别的那一层。 |
| 每到场尾都讲一个人生道理 | 分开读收束前后的两句。结论若只是翻译刚发生的事，可收在具体变化处；承担叙述声音的评论应留。 |
| 每一段都从动作写到感悟，句子被切得一样短 | 按人物的一口气读。正在犹豫的人可能需要一个拖长的从句；中断回应可能需要留白。避免按配额造碎句、凑五感或随机换标点。 |
| 不同人物轮流说同一种漂亮话 | 对谁说、想躲开什么、能用什么称呼？看人物在这个场合是否肯把整句讲完。允许结巴、套话和有意拗口的客气话。 |
| 一转述就断言别人的内心 | 逐句辨认感受者与消息来源。检查世界中发生的事、人物信以为真的事，以及读者在此刻有条件推断的事。 |
| 为避重复换了称谓或术语 | 读者还能确定施事、受事和指代吗？查中文搭配。反复使用准确的名字常常更清楚。 |

## 交稿时的核对

1. 新稿先按本书的文风写完约定的章节或段落。接手纯润色时，圈定目标和受保护信息，包括时间、因果、否定、条件、事件完成与否、所知、伏笔、独立信息及指定保留的原话。
2. 挑出能说明影响的几处，改动恰够解决问题的句段。只获语言编辑授权时，以原有行动、道具、经历和关系为边界。需要让人物换个决定才能解决的场景问题，留在正文之外说明，按实际改稿授权处理。
3. 将改前改后接回上下段读一次。有没有把猜测说成事实，给对白添了说教，或者损失一句独有的信息？检查段落展开和交付篇幅。大幅压缩或扩写属于实质删改，须在获准的范围内注明。不要用全文摘要交付章节润色。
4. 交付清洁文本。依据和仍需处理的问题按需另放；用户只要正文时直接给正文。没有可定位的问题就保留。心理、概述、自由间接引语、长句、叙述评论与反复都可以是本书的声音。靠错字、病句、强行口语化、夸张反应或虚构亲历制造的“自然感”会损害它。

## 原创教学示例

以下片段仅用于演示编辑判断，不计入作品或进度。

**说明文，消除施事含混。** 原句为“校样单由值班编辑签字以后，归档操作由值班编辑进行。”可改为“值班编辑签完校样单，再把它归档。”签字和归档仍由同一人执行，先后条件也还在。若原文把归档交给另一人，这个改法就不成立。

**小说，删解释，留下辩解。** 原段为“‘我没拆。’她说。封口原来就松，这也算拆？她拿不准弟弟信没信。弟弟是否相信她的话，她心里实在没底。”交稿可写作“‘我没拆。’她说。封口原来就松，这也算拆？她拿不准弟弟信没信。”删去的末句没有增加认识。“这也算拆？”留下她给自己的辩护；换成“弟弟早知道她撒谎”会越过视角，还会替读者裁定那封信究竟怎么了。

**小说，保留有作用的长句和反复。** “等水开，等壶盖响，等她想好第一声该叫爸还是叫周师傅，她就去接，电话偏在这时候断了。”这里三个“等”把推迟接听的片刻拉长，两个称呼让读者听见关系的分量。保留原句。若拆成三次斩钉截铁的决定，迟疑会消失；若补上父女过去的冲突，就替这段未说出口的话编了来历。
