# AI 小说创作工作室

这里可以同时维护多部中文小说。人决定想写什么、哪些东西必须保住，AI 把意图发展成可读的小说，并维护下一次续写所需的资料。每部作品有独立的设定、正文、计划和工作状态。

## 从一句想法开始

1. 直接说你想做什么。可以带一段语音转写、一个画面、一份旧稿，或只给一句修改意见。
2. 讨论候选时只比较方向。委托发展其中一个创意时，主创按[建作步骤](templates/README.md)创建作品、登记编号和简报。可开写条件取决于眼前要交付的章节。
3. 回到已有作品，在[作品索引](novels/README.md)按编号或标题定位。作品 README 通向状态页，那里记录接续位置和待同步事项。提交明确的续写范围或修改目标即可。

**示例委托**（仅说明用法）

- “比较两个出发点：女儿替母亲寄出一封旧信，或者母亲亲自去取一封退信。我想写的是两人都没问出口的事，先只讨论。”
- “选退信的方向，建立一部中篇。保留母女始终叫对方全名的习惯，先给我总纲和近期章纲。”
- “继续我刚才指定的作品，接着当前修订稿写下一章。让她第一次想把信还回去。”
- “只改这一段对白。女儿仍然只是猜测信是谁写的，母亲第二次叫她全名要保留。”
