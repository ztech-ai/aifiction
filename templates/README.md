# 新建作品 · 模板 1.0

[作品模板入口](novel/README.md)包含空白工作资料。版本 1.0 标记目录与字段约定，作品 README 保留创建时的版本。升级模板默认服务新作；旧作需要新字段时，先比对其个性化约定，按任务逐项迁移。

## 分配编号与复制

只比较创意时可以直接在对话中交付方案。明确要求立项或委托把选定创意发展成作品，才登记一次。先查[索引](../novels/README.md)、已归档编号和磁盘上的作品目录，取历史最大号加一，至少三位，首号为 001。并行立项由一人负责分号和索引更新。短名选一个稳定、适合做路径的名字，避开斜杠及目录特殊字符。

从仓库根开始，以下为**命令示例**，将参数换成本次实际编号、短名。确认目录名未占用后逐步执行，已有目标目录时停下核对现场。

```sh
id=001
short=作品短名
book="novels/${id}_${short}"
mkdir -- "$book" &&
  cp -R templates/novel/. "$book/" &&
  mv -- "$book/AGENTS.template.md" "$book/AGENTS.md"
```

- 在新作品 README 与作品指令中把 `{{ID}}`、`{{TITLE}}` 换成稳定编号和显示标题。若标题暂定，可在定位栏注明。修正 README 的指令链接目标为 `AGENTS.md`，删除 README 末尾的“模板使用注”整段。目录层级相同，其余相对链接保持有效。
- 填写已知的定位、简报、当前任务和下一步，核对其他资料的空状态。后续随委托补充。新作无已完成章节时，章节索引保持空表。探索片段按需单独保存，注明是否采用。
- 检查新目录内无未替换变量、模板文件名或示例说明。按链接打开作品指令、状态页、章节索引及其余资料，核对编号、目录和显示标题。在作品索引登记实际路径、类型和阶段，再复查索引与目录一一对应。若复制或登记中断，先检查目标目录及索引后补齐。
- 改书名时先改显示标题及索引；必须移动目录时同批修复所有引用。每个作品保留自己的资料版本与约定。
