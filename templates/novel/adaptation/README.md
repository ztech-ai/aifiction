# 改编入口

当前预留，尚无改编项目。收到明确改编委托后，从[章节索引](../chapters/README.md)锁定小说来源版本，再按委托的媒介、篇幅、观众和交付范围建立资料。

## 启用时填写

- **来源**　注明小说编号、涵盖章节的稳定 ID 与展示顺序、来源稿次或可恢复版本。若有连载版与内部修订版并行，写明采用哪一版。
- **定位与取舍**　记目标媒介、受众和必保的阅读体验或关系，以及心理、叙述时间或语言特征将如何转化。
- **映射与产物**　为涉及的人物、小说章节／场景与改编场景建立对应关系，注明合并、拆分、移序或新写的理由。按需要链接分集大纲、剧本、分镜与制作资料，标记各自版本。
- **变更**　小说更新后先检视映射，记录此次改编承接的范围；改编新增的事件留在改编版本。回写小说须依据相应创作委托单独处理。

**自检**　每个关键改编决定能追溯到明确的小说版本或改编理由吗？对照两个版本时能说清各自保留的事实和体验吗？
