# 审稿记录

尚无报告。开篇体验、关键转折、卷末回看或实质修订需要跨段追踪时，在此保存对应范围的报告。能当场修正的轻微疏漏可直接处理。

## 报告字段

- **对象与任务**　列出范围、章节 ID、稿次和此次要判断的问题。
- **阅读条件**　注明真实读者反馈、AI 模拟审读或编辑复核，列出实际可见材料和截止位置。模拟首次阅读时先读该位置以前的正文与公开前情，记下当时理解、期待、情绪及继续阅读的动力，再查设定与后文。已看过谜底须注明。
- **发现与证据**　每条注明位置、短引或动作细节、问题和阅读影响。区分事实矛盾、叙事问题与风格偏好。对悬念要指出文本给了什么理由让读者等待，对信息缺失说明哪一个决定因此无法理解。
- **处理与复核**　给出具体改法、可能损失及处理结果（已改／保留／待处理），注明对应稿次或后续计划。意见相左时用正文效果说明取舍。

**自检**　另一位编辑能从指定版本找到证据、复查效果吗？若保留原文，它承担的作用说清楚了吗？
