# 创作简报

立项时把交谈里值得写成小说的东西留下来。接手续作或修订时，只补本次取舍会用到的约束。在“作品约定”列填写，用户原话值得留的可摘录一两句。

| 要回答的问题 | 填写提示 | 作品约定 |
| --- | --- | --- |
| 最初为什么想写？ | 留下打动人的画面、声音、关系、情绪或疑问。语音转写有歧义，保留影响剧情的原词。 | |
| 改了什么就失去写它的理由？ | 写出必保元素及其作用。区分用户明确要求与主创可自由发展的部分。 | |
| 谁会想读，带着怎样的类型期待？ | 写可能被这段经历吸引的读者，以及最值得兑现的一项期待。 | |
| 从开篇读到收尾，想让人经历什么？ | 写起初牵挂什么，何种积累能让一次选择或一个寻常细节到后来有分量。 | |
| 多长，以什么方式读到它？ | 写短篇、分卷或连载倾向，已约定的篇幅、更新或交付尺度。 | |
| 有哪些内容边界？ | 写可涉及的题材、呈现尺度，以及用户指定避开的内容。 | |

## 待验证的工作假设

尚无。有重要未知时写下暂用判断、影响范围和什么证据会改变它。改变核心意图时更新本页，并在[决定记录](../memory/decisions.md)留下变更依据。

## 与其他作品的关系

尚无。用户指定续集或共享背景时，填写关联作品编号、所需章节或设定及来源版本，注明同一连续性、平行版本或仅复用创意。

## 自检

若要删掉一个受欢迎的桥段，这份简报能帮你判断删后是否还保得住原意吗？目标读者在文中能通过什么经历感受到那项阅读承诺？
