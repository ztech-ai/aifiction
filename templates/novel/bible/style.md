# 本作品的叙述声音

准备试写、开始正式写作或判断改稿得失时使用。把本作可听见、可辨认的语言选择写在第三列。没有获认可的样稿时，先把适合当前任务的选择注明“暂定”，读到实际段落后再校准。

| 维度 | 填写问题 | 本作约定与适用范围 |
| --- | --- | --- |
| 人称、视角与距离 | 谁在说，谁在感受？能否进入他人内心？视角转换给读者什么信号？ | |
| 时间与节奏 | 从何时回看，哪些时刻放慢或跳过？句子何时需要绕回，段落在哪里换气？ | |
| 时代语体与词汇 | 叙述者会自然使用哪些称谓、行话或抽象词？哪些词会让时代或身份显得错位？ | |
| 心理与叙述评论 | 人物的念头怎样渗进叙述？叙述者何时有意拉开距离，留给读者判断？ | |
| 修辞密度 | 允许哪些反复、长句、停顿或比喻？意象从谁的生活经验中来，何处宜收住？ | |
| 对白与人物声音 | 叙述声和对白如何相处？切到另一人物时凭什么能听出差别？各人的称谓与说话习惯见[人物卡](characters.md)。 | |
| 受保护的特征 | 写明要保留的语言现象、叙事作用及适用段落或人物。 | |

## 文风参照与反馈

尚无。优先记用户认可的本作片段，用文件、章节 ID、稿次及段落起句定位。写清喜欢的是距离、节奏还是措辞，适用于一句、一场、一个人物阶段还是整部作品。若参照外部作品，只提炼可描述的写法，将人物、事件和具体表达留给本作原创。

## 自检

这一段最亲近谁的判断，有哪个词会泄露此人尚未知道的事？修改让指定的语气、节奏或潜台词更清楚了吗？需要具体审校时，查[公共文字审校与示例](../../../docs/prose-style.md)。
