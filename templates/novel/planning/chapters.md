从[故事总纲](../bible/story.md)推进到下一批可写章节时填写。远处保留阶段方向，仅展开眼前会写的章。以下栏位记录计划。实际摘要随成稿进入[章节索引](../chapters/README.md)。

## 近期章纲

每个待写章复制下列字段，用实际分配的稳定 ID 和暂题作小标题。插章或调序时检查相邻计划和索引的展示顺序，沿用原有 ID。短篇可合并相关字段，观察或抒情场景可围绕注意力、时间感和意义的变化来写。

| 字段 | 填写提示 | 本章计划 |
| --- | --- | --- |
| 稳定 ID、暂题与位置 | 按计划阅读位置记前后章或阶段，注明所承接的正文版本。 | |
| 视角与进入时的处境 | 谁在何时何地，从哪段行动、关系或余情接入？首章写读者的进入点。 | |
| 本章作用 | 推进什么，或让读者在何处停留、重新察觉什么？ | |
| 阻力、选择与后果 | 哪个条件使最省力的办法行不通？谁作了什么选择，哪项代价会延续？ | |
| 关系或认知 | 谁改变了对谁的看法或态度？若仍然坚守，读者对其坚守多知道了什么？ | |
| 信息释放 | 依次写实际情况、人物可获得的线索及其理解、读者此刻可推知的部分。 | |
| 情绪进程 | 由怎样的期待或不安起步，在哪个动作、迟疑、想法或细节处发生变化？ | |
| 伏笔及承接处 | 本章在何处埋设、推进或兑现？注明前文依据与预期呼应位置。 | |
| 收尾动力 | 哪个后果、未说完的问题，或哪一笔余韵会随读者进入下一章？ | |

## 开写前自检

简报、故事方向、关键人物、必要规则、文风和本章计划，能支持眼下要写的范围吗？按展示顺序核对直接前章的实际落点。若前章已改，本章哪项期待、所知或关系要随之调整？写完以实际正文校准后续计划。
